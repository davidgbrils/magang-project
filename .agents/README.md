# Agent Resources

Folder ini menyimpan resource agent yang relevan untuk repository `magang-project`.

## Skills lokal

- `skills/i-have-adhd`: output action-first dan mudah diikuti.
- `skills/caveman`: komunikasi teknis ringkas.
- `skills/caveman-commit`: pesan Conventional Commit ringkas.
- `skills/caveman-review`: code review ringkas per temuan.
- `skills/caveman-compress`: kompres file instruksi tanpa menghapus isi penting.

Skill ini dicopy dari instalasi Codex pada 15 September 2026. Perbarui kedua lokasi bila ingin memakai versi baru.

## Plugin

Lihat `plugins/active-plugins.json`. File itu adalah inventaris plugin yang aktif di lingkungan Codex, bukan installer atau pengganti konfigurasi global Codex.
